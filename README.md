# Tengen
This is the programming for the tri-joint arm movement. it works through three inputs, an x-coordinate, a y-coordinate, and the angle at which the arm is to come in. 
Im still new to coding so its kind of sloppy and jank, but if you want to copy or imporve it I fully support it, this is a passion project of mine and would love to see its full potentail.

There will be a Z-axis and potential for voice activation via rasberry pi eventually.
